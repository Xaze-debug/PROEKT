# Удаление коммита или последнего изменения (HEAD)
## Удаление "неправильного действия"
```bash
git reset --soft HEAD~1
```
## Полное удаление коммита
Если уже проще начать заново
```bash
git reset --hard HEAD~1
```

**Можно запоминать так:**
Soft - мягкий
Hard - жесткий 
***

# Взять только нужное

Например кто то сделал нужный тебе коммит но он в другой ветке.
Для  того что бы взять его себе понадобится хэш (ID) нужного коммита
#### Показываем себе историю коммитов
```bash
git log
```
#### Переключаемся на свою ветку
```bash
git checkout feature
```
#### Забираем нужный коммит
```bash
git cherry-pick a1b2c3d
```
Теперь этот коммит появится в вашей ветке
***
# Журнал твоих действий Reflog
```bash
git reflog
```
#### Нужный файл нашелся?
```bash
git checkout HEAD@{5}
```
5 - это кол-во действий назад. Т.Е. вы откатывайтесь на 5 действий назад

# Склеивание коммитов (Squash)
Например у тебя много коммитов которые нужно совместить в один 
```bash
rebase -i HEAD~3
```
Откроется текстовый редактор со списком коммитов. Для самого верхнего (Самый старый) осталяют pick, остальные меняют слово pick на squash
Сохраняем файл

# Временное хранилище 
Например ты что то делал и вдруг ты нужен на главной ветке.
#### прячем всё
```bash
git stash push -m "Название"
```
#### Смотрим всё ли сохранилось
```bash
git stash list
```
#### Достаем то что сохранили
```bash
git stash pop
```
